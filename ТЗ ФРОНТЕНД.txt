Цель задания
Получение практических навыков разработки frontend-приложений с использованием современных инструментов.

Технологический стек
Frontend должен быть реализован с использованием:

Vite
React
TypeScript
Axios

Требования
Frontend-приложение должно:

взаимодействовать с backend через HTTP API;
реализовывать основные CRUD-операции;
использовать модульную архитектуру.
Подзадачи (Тема 9 — TypeScript)
При разработке необходимо применить следующие возможности TypeScript:

Базовые конструкции
переменные и типизация;
именованные функции;
анонимные функции.
Работа с типами
массивы;
объектные типы;
перечисления (enum);
псевдонимы типов.
Продвинутая типизация
Использовать:

тип Any;
тип Unknown;
тип Void;
опциональные параметры функций;
функции как параметры.
Дополнительные возможности
Применить:

деструктуризацию;
операции Rest и Spread;
перегрузку функций;
сужение типов;
аннотации типов.
Работа со структурами данных
Использовать:

многомерные массивы;
неизменяемые массивы;
кортежи;
объединения типов;
литеральные типы;
пересечение типов;
значения Null и Undefined.
Продвинутые концепции
Рассмотреть:

иерархию типов;
структурную типизацию;
ковариантность и контравариантность.
