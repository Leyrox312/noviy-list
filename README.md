Архитектура:
У нас есть несколько уровней
1. Фронтенд, он же клиентская часть которая находится по директории /client
Собрано при помощи typescript, vite и react
react-router-dom используется для маршрутизации дабы навигация между страницами была более плавной без перезагрузок браузера
Локальные состояния userstate используются для форм и фильтров
authcontext.tsx используется для глобального сохранения статуса админа
Запросы к серверу вынесены в index.ts и выполняются через библиотеку axios
2. Бекенд, он же серверная часть находится в директории /server
собрано при помощи Next.js сервер работает на порту 3000
маршруты API Routes  организованы по папкам в src/app/api каждая сущность имеет свой файл route.ts который обрабатывает методы get post put delete
для обработки параметров используется динамическая маршрутизация которая позволяет работать с конкретными записями по их идентификаторам
3. БД. Проект использует файловую систему хранения данных для наибольшей портативности
data.json хранит всю информацию о предметах классах и правилах
db.ts содержит функции readDb и writeDb которые считывают и записывают JSON-файл при каждом изменении
4. стиль и юишка
глобально находится в terminal.css, там есть все что нужно - цвета, шрифты анимки и эффект crt монитора которые отчетливо видны на картинках

ИНСТРУКЦИЯ ПО ЗАПУСКУ!!!!!
1. Скачать проект из гитхаба любым удобным способом
2. Распаковать его в любое удобное место
3. Открыть папку noviy-list в любом удобном виртуальном окружении
4. В новом терминале перейти в директорию сервера через команду cd server
5. Выполнить команду npm ci 
6. Выполнить команду npm run dev для запуска бека
7. Открыть новый терминал и перейти в директорию клиента через команду cd client
8. Выполнить команду npm ci
9. Выполнить команду npm run dev для запуска фронта
10. Кликнуть по ссылке напротив local
11. Вы восхитительны!
12. Если захочется зайти на страницу и просмотра документации то вам нужно добавить /api/docs в конец открытой страницы бекенда
