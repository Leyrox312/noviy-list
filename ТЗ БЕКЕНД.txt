Цель задания
Освоение разработки серверной части веб-приложения и создания HTTP API.

Допустимые технологии
Backend должен быть реализован с использованием одного из стеков:
JavaScript
Next.js
Требования
Backend должен включать:

Реализацию HTTP API
Минимум 5 эндпоинтов
Интеграцию с базой данных
Реализацию CRUD-операций
Подзадачи
Работа с HTTP API
Необходимо реализовать:

обработку HTTP-запросов;
CRUD-операции;
взаимодействие с базой данных.
Документирование API
Необходимо:

реализовать документацию OpenAPI / Swagger;
описать структуру запросов и ответов.
Тестирование API
Для проверки API необходимо использовать:

Postman
HTTPie
Безопасность
Реализовать:

аутентификацию пользователей;
авторизацию пользователей.
