ТЗ к проекту fallout dnd


Общее описание системы:
Проект представляет из себя сайт с системой редактирования и добавления страниц через логин admin’а
ЦА проекта - фанаты фоллаута, днд, и прочего…
Сценарии использования:
Просмотр правил игры
Поиск информации о расах, классах и пр.
Изучение механик игры
Просмотр списков оружия и брони
Регистрация пользователя
Добавление и редактирование статей юзерами с правами админа

Функциональные требования:
Основные функции системы: 
Система должна обеспечивать
регистрацию и авторизацию юзеров
просмотр страниц сайта без авторизации
поиск и фильтрация контента по категориям
создание, редактирование и удаление статей юзеров с правами админа
адаптивный интерфейс
панель администратора
CRUD
Сущность: статья
C - создание статьи
R - просмотр статьи
U - редактирование статьи
D - удаление статьи

Сущность: категория
C - создание категории
R - просмотр категории
U - редактирование категории
D - удаление категории
Архитектура системы:
Система строится по модели клиент-серверного приложения
FRONTEND:
Отвечает за взаимодействие с пользователем и отображение интерфейса
Используется:
React.js
HTML
CSS
JavaScript
Typescript
Axios
Vite

BACKEND:
Обрабатывает запросы, логику и работу с БД
Используется:
Next.js

Взаимодействия фронтэнд и бэкэнд:
Обмен данными осуществляется через http API в формате JSON

Пример: Фронтэнд отправляет запрос:

GET /api/races

Бэкэнд возвращает

[
  {
    "id":1,
    "name":"Гуль",
    "bonus":"+2 телосложение"
  }
]

Требования к пользовательскому интерфейсу
Страницы:
Шапка:
1. сделать три выпадающих списка с ссылками на страницы, списки должны быть логически распределены (где-то правила, где-то расы и классы, где-то предметы и так далее)
2. сделать кнопку с логотипом проекта которая отправляет на главную страницу

Подвал:
1. Дописать важную инфу по типу все права принадлежат bethesda и так далее
2. Сделать ссылку на медиа. При нажатии должно перебрасывать на рикролл
3. Сделать ссылку на техподдержку. При нажатии должно перебрасывать вот сюда: https://www.youtube.com/shorts/Qta9chteIug
4. Добавить контактную информацию если это кому-нибудь понадобится когда нибудь
5. Добавить дату создания сайта (год)

Главная страница: 
1. Написать красивый текст с приветствием, добавить кнопку которая будет перекидывать на страницу быстрого старта
2. вся основная информация о проекте так же на этой странице


Быстрый старт:

1. Абзац "Как этим вообще пользоваться?". В нем будет краткая информация о том, как пользоваться данной книгой правил, рекомендации и предпуреждение что стоит ознакомится с обычной книгой правил DND 5 редакции если никогда не играли раньше в днд/никогда не вели партии в днд
2. Под абзацем "Как этим вообще пользоваться?" добавить кнопку, при нажатии на которую ведет на страницу с книгой игрока dnd 5e
3. Алгоритм создания персонажа. В этом абзаце нужно написать как создавать персонажа. Алгоритм имеет 8 пунктов, напротив каждого из 8 пунктов должна находится кнопка с переходом на страницу с нужной информацией (1 пункт выберите расу персонажа, напротив кнопка ведущая на страницу с списком рас и так далее.)
4. Вопросы и так далее. В абзаце будет информация о том как связаться с тем кто делал проект, либо тг, либо ссылка на рикрол. Под этим абзацем должны быть две кнопки. Одна ведущая на подвал главной страницы где есть методы связи, а вторая на официальную википедию по вселенной fallout на русском языке (убежище wiki)

Механики:
На странице есть разные категории механик под которыми есть их карточки, внутри карточек будет информация о механиках
Расы:
Сделать списком из карточек. В карточке высвечивается картинка и название расы, при нажатии будет перекидывать на страничку расы где есть другая картинка расы и описание и бонусы

Классы:
Представляет из себя страницу с списком классов. Выполнено в качестве карточек подобно системе рас, есть пикча и название класса при нажатии перекидывает на страничку класса там есть таблица с уровнями и перками и бонусами которые будут, другая пикча, описание класса куда идёт все остальное

Происхождения:

По сути абсолютно то же самое что и с расами с классами

Перки:

Короткий абзац с текстом что такое  перки и список перков. Каждый из перков с коротким описанием, тематической картинкой, названием и требованием находится в прямоугольнике по типу того что было в расах

Оружие:

Есть категории оружия, все, пистолеты и тд. Там нужно сделать карточки где будет информация о оружии, его хар-ки, стоимость и тд. При создании они будут подразделятся под один из их видов

Броня:
Страница с видами брони оформляется по такому же принципу как и страница с видами оружия, есть несколько типов брони и в них есть карточки



Медикаменты, провизия, аммуниция, инструменты оформляются по тому же принципу как и остальные виды снаряжения


СТИЛЬ: Стилистика Fallout 3, стилизовано под экран терминала

Страница редактирования: 
Стилизировано под общий стиль сайта. Есть разные поля ввода для разных страниц, где-то можно будет вставить ссылку на изображения
